# Color profiles

`Display-P3.icc` is the Display P3 profile distributed by the [ICC Display P3 registry](https://registry.color.org/rgb-registry/displayp3). The registry identifies Apple as the responsible organization and provides the profile. It is stored here so the test JPEG generator does not depend on a host's installed ColorSync profile.
